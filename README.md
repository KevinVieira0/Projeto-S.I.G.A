# Sistema de Indicação e Gerenciamento do Aprendiz (SIGA)

> Plataforma web para gerenciamento de alunos, empresas e vagas de estágio e jovem aprendiz.

## 📖 Sobre o Projeto

O **Sistema de Indicação e Gerenciamento do Aprendiz (SIGA)** é um projeto acadêmico desenvolvido para o **Curso Técnico em Desenvolvimento de Sistemas** do **SENAI Mariano Ferraz**.

O sistema tem como objetivo modernizar o processo de gerenciamento realizado pelo coordenador de estágios, centralizando em uma única plataforma informações atualmente distribuídas entre planilhas Excel, Power BI, formulários e e-mails.

A aplicação permitirá o gerenciamento de alunos, empresas e oportunidades de estágio ou jovem aprendiz, proporcionando maior agilidade na busca de candidatos compatíveis com cada vaga.

---

# 🎯 Objetivos

- Centralizar o gerenciamento de alunos, empresas e vagas.
- Facilitar o acompanhamento dos processos seletivos.
- Automatizar filtros de candidatos.
- Reduzir retrabalho causado por planilhas duplicadas.
- Melhorar a organização das solicitações das empresas.
- Disponibilizar dashboards para apoio à tomada de decisão.
